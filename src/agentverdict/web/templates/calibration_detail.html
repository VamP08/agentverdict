Bias probes

Everything above asks how far this judge is from the people. A probe asks a question with no people in it: re-judge the same trajectory under a prompt that differs in a way that should not matter, and watch whether the verdict moves. The headline of each probe is the judge's own test-retest noise — whether two byte-identical calls even agree — because no shift underneath it means anything until that floor is known.

These panels read stored probe rows only, so opening this page never calls a model and never starts a sweep. agentverdict probe {{ report.judge_name }} is what records one.
